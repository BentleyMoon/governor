Governor

A 200-line keyword router for OpenAI-compatible APIs. It classifies each request and sends it to the cheapest model tier that suits the work. Open source under the MIT licence.

Evidence status

The savings figures come from 35 hand-rated turns against simulated cloud pricing, roughly nine per workload, and the turn-level data is not published. The measured mixed-coding figure is a saving of about 49%. These numbers are indicative, not a validated benchmark, and no learned classifier was tested against the keyword router.

How it works

ECONOMY    greetings, acks, simple lookups, follow-ups   cheap fast model
STANDARD   bounded coding, implementation, reasoning      capable model
FRONTIER   architecture, multi-file refactor, security    strongest model

Classification is keyword-based, about 200 lines of Python. The idea under test is that the signal that decides the tier is visible in the prompt itself.

What it is not

Not a paid product and not a hosted service: there is no commercial tier. Not a marketplace: routing picks by workload, not by provider price. Not a fine-tuned classifier.
