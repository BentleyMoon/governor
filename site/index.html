How it works

1. Classify

~200 lines of keyword regex look at the request. Coding terms route one way. Architecture terms route another. Greetings route to a tiny fast model.

2. Route

Three tiers. ECONOMY for chat and acks. STANDARD for bounded coding. FRONTIER for architecture and security work. You set the model behind each tier; we pick which to call.

3. Save

Per-tier spend in your dashboard. We invoice a flat percent of the savings. If we don't save you money, you don't pay.

Why a regex

The working hypothesis, carried over from the parent research program, is that the decision-relevant signal for tier selection is observable in the words of the prompt. So the classifier is keyword-based.

We have not benchmarked this against a learned router. There is no head-to-head here, so nothing on this page shows a regex beating a fine-tuned classifier. If that comparison is what you need, RouteLLM is the work to read.

Research

Governor is the §5 finding from a multi-domain research program on boundary mechanisms — small wrappers that observe system-environment boundaries and outperform large internal-state models. The full paper covers three findings (986+ trials, including the multi-file wall in code repair and momentum protection in continual learning) and 14 honest negative results.

FAQ

Will this break my app?

No. OpenAI-API-compatible. If we go down, point base_url back at OpenAI directly — back online in 10 seconds.

What about latency?

Routing decision adds ~2ms. ECONOMY-tier responses are faster than frontier responses, so average latency on Economy/Standard turns drops.

What if a request is misrouted?

You can pin specific request types to specific tiers. Keyword list is editable per-deployment.

Where does the data go?

Self-hosted by default. Cloud version available. We never store the request body — only token counts and tier classification.

Who built this?

Bentley Moon, independent AI researcher. Built on the Lattice execution gateway (13,303 LOC, 133 tests). The routing figures come from 35 measured turns; the parent synthesis paper documents the wider program but does not contain this measurement's methodology, which is not yet written up.
